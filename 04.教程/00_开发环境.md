# 00 · 开发环境：VS Code、ESP-IDF 插件与 ESP-IDF v6.1.1

零基础按本章装好工具后，**01～09 章共用同一套流程**：打开对应章节目录 → 配置目标芯片 → 编译 → 烧录 → 观察现象 / 看日志。

**下一章**：[01 · GPIO LED](01_GPIO_LED.md)

## 本章目标

- 安装 **Visual Studio Code** 与乐鑫官方 **ESP-IDF 扩展**；
- 通过扩展内置安装器部署 **ESP-IDF v6.1.1**（含工具链、Python 环境、`idf.py`）；
- 把本仓库放到 **纯 ASCII 路径**，避免 Windows 下 cmake 因中文路径崩溃；
- 识别板子 **USB-Serial-JTAG** 烧录口的 COM 号，并会用命令行或 VS Code 完成第一次编译、烧录。

## 硬件与仓库

- **CX0001 ESP32-S31 Module Lite** 开发板；
- USB-C 数据线（需支持数据）；
- 仓库建议路径：如 `D:\dev\CX0001_ESP32_S31_Module_Lite_Board` 或 `E:\GitHub\CX0001_ESP32_S31_Module_Lite_Board`（**纯 ASCII、勿含中文/空格**；**尽量不要放在 C 盘**，见下文）。

## 一、安装 Visual Studio Code

1. 打开 [Visual Studio Code 官网](https://code.visualstudio.com/)，下载 Windows 安装包并安装。
2. 可选勾选「添加到 PATH」。
3. 暂不必单独装 C/C++ 扩展（ESP-IDF 扩展会处理依赖）。

## 二、安装 ESP-IDF 扩展

1. VS Code → **扩展**（`Ctrl+Shift+X`）。
2. 搜索 **Espressif IDF**（Espressif Systems）→ **安装**。

## 三、安装 ESP-IDF v6.1.1

1. 命令面板（`Ctrl+Shift+P`）→ **`ESP-IDF: Configure ESP-IDF extension`**。
2. 选 **Express**。
3. **安装路径不要选 C 盘**（系统盘易空间不足、权限/杀软干扰多）。在向导里把 **ESP-IDF** 与 **Tools** 指到其他盘，例如：
   - IDF：`D:\Espressif\frameworks\esp-idf-v6.1.1`
   - 工具链：`D:\Espressif\tools`  
   （盘符按你机器改成 `D:`、`E:` 等均可，保持路径无中文、无空格。）
4. 版本选 **ESP-IDF v6.1.1**（或同系列最新 6.1.x）。
5. 等待下载完成 → **`ESP-IDF: Doctor command`** 确认无报错。

已有本地 IDF 时选 **Use existing setup** 并指定 `IDF_PATH`。

### `esp32s31` 与 `--preview`

ESP32-S31 在 v6.1 为 **预览目标**。在**外部终端**手动执行 `idf.py` 时需加 **`--preview`**。VS Code 扩展在编译/烧录时通常会代为处理。

## 四、打开示例工程

1. **文件 → 打开文件夹** → 例如 `...\03.Sketch\01_GPIO_LED`。
2. 每章为独立 ESP-IDF 工程；换章时重新打开对应文件夹。
3. 首次提示选芯片 → **esp32s31**。

## 五、工程配置（每章通用）

| 步骤 | VS Code | 命令行 |
|------|---------|--------|
| 设 target | `ESP-IDF: Set Espressif Device Target` → esp32s31 | `idf.py --preview set-target esp32s31` |
| menuconfig | `ESP-IDF: SDK Configuration editor` | `idf.py --preview menuconfig` |
| 选串口 | `ESP-IDF: Select Port to Use` | `idf.py --preview list-ports` |

烧录口为 **USB-Serial-JTAG**（见 [04_USB_SERIAL.md](04_USB_SERIAL.md) 与 05 章双口说明）。

## 六、编译与下载

**VS Code**：状态栏 **Build** → **Flash** → **Monitor**，或 **Build, Flash and Monitor**。

**命令行**（在某一章工程目录内）：

```powershell
idf.py --preview set-target esp32s31   # 每目录首次
idf.py --preview build
idf.py --preview -p <COM口> flash monitor
```

- 编译成功：`Project build complete`。
- 退出监视：`Ctrl + ]`。

## 七、验证环境

按 [01_GPIO_LED.md](01_GPIO_LED.md) 打开 `03.Sketch/01_GPIO_LED`，编译烧录后 LED（GPIO38）约 0.3 s 闪烁一次。

## 八、常见问题

| 现象 | 处理 |
|------|------|
| cmake 路径崩溃 | 工程移到纯 ASCII 路径，`idf.py fullclean` 后重编 |
| 无 `idf.py` | 用 **ESP-IDF Terminal** 或运行 `export.ps1` |
| 无 COM 口 | 插 **USB-Serial-JTAG** 口，换线，查设备管理器 |
| 未知芯片 | `set-target esp32s31` 且命令带 `--preview` |
| IDF 装在 C 盘后异常 | 用扩展重新配置，把 IDF/Tools 迁到非 C 盘；或 **Use existing setup** 指到新路径 |
