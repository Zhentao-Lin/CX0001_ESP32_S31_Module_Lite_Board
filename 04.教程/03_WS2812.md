# 03 · WS2812 板载 RGB

**示例工程**：[`03.Sketch/03_WS2812`](../03.Sketch/03_WS2812)

`led_strip` + RMT：红→绿→蓝→白→灭，300 ms/色，亮度 50/255。

> [00_开发环境.md](00_开发环境.md)。无串口。

## 本节目标

- WS2812 单线协议；`set_pixel` + **`refresh`**；
- GRB 顺序；亮度单独缩放。

## 用到的硬件

- WS2812（GPIO39，1 颗）。

## 工程配置

1. 打开 `03.Sketch/03_WS2812`，`set-target esp32s31`。
2. `idf_component.yml`：`espressif/led_strip ^3.0.3`，首次 build 需联网。
3. menuconfig：**Example Configuration**（GPIO、颗数、亮度、RMT 10 MHz）。

## 编译与下载

```powershell
idf.py --preview build
idf.py --preview -p <COM口> flash
```

## 编程效果

RGB 按红绿蓝白灭循环，偏暗（约 20% 亮度）。

## 代码逐段讲解

源码：[`main/ws2812_main.c`](../03.Sketch/03_WS2812/main/ws2812_main.c)。

### 1. Kconfig 与 `s_steps[]`

宏来自 menuconfig；`s_steps[]` 为满幅 RGB（红绿蓝白灭）。`apply_brightness()` 做 `channel * WS2812_BRIGHTNESS / 255`，与 Arduino `setBrightness(50)` 一致。

### 2. `ws2812_init()`

`led_strip_config_t` 指定 GPIO、灯数、`LED_MODEL_WS2812`、`LED_STRIP_COLOR_COMPONENT_FMT_GRB`。`led_strip_rmt_config_t` 设 `resolution_hz = 10 MHz`（勿改低，否则 WS2812 时序错）。`led_strip_new_rmt_device()` 分配 RMT 并返回句柄。

### 3. `apply_brightness`（细节）

```c
return (uint32_t)channel * WS2812_BRIGHTNESS / 255;
```

先按满幅写颜色表，再统一缩放到约 20% 通光；改 menuconfig 亮度无需改 `s_steps[]`。

### 4. 主循环三步

对每个 `s_steps[i]`：① `led_strip_set_pixel` 写缓冲；② **`led_strip_refresh`** 才推到数据线；③ `vTaskDelay(STEP_MS)`。多灯时对 `led=0..N-1` 循环 set_pixel，再一次 refresh。

## 常见问题

- 不亮：GPIO39；红蓝反了改 RGB 格式；勿降低 RMT 分辨率。
