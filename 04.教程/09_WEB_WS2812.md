# 09 · 网页控制 WS2812

**示例工程**：[`03.Sketch/09_WEB_WS2812`](../03.Sketch/09_WEB_WS2812)

Wi-Fi STA + `esp_http_server`：浏览器 `http://<板子IP>` 控颜色与亮度（GPIO39 WS2812）。

> [00_开发环境.md](00_开发环境.md)。

## 本节目标

- 静态页 + REST 风格 GET；
- `/ctrl`、`/status` JSON；
- 与 03 章相同的 `led_strip` 驱动。

## 用到的硬件

- WS2812（GPIO39）、2.4G 路由器、手机/PC 浏览器。

## 工程配置

1. 打开 `09_WEB_WS2812`，`set-target esp32s31`。
2. menuconfig：
   - **Wi-Fi station example**（SSID/密码）；
   - **WS2812 web example**（GPIO、亮度、HTTP 端口，默认 80）。
3. `led_strip ^3.0.3`，首次 build 可拉组件。

## 编译与下载

```powershell
idf.py --preview build
idf.py --preview -p <COM口> flash monitor
```

日志：`Got IP: ... -> open http://...`，同网段浏览器打开该 URL。

## 网页接口

| 路径 | 方法 | 说明 |
|------|------|------|
| `/` | GET | 控制页 |
| `/ctrl?color=&brightness=` | GET | 设灯，返回 JSON |
| `/status` | GET | `{"color":"red","brightness":50}` |

`color`：`red` / `green` / `blue` / `off`；`brightness`：0–255。

## 编程效果

- 点颜色按钮，灯变色，页内状态同步；
- 滑块改亮度后点「应用」；
- 多客户端每 2 s 轮询 `/status`。

```
I (o) ws2812_web: Got IP: 192.168.1.123 -> open http://192.168.1.123
I (o) ws2812_web: Web server ready on port 80
I (o) ws2812_web: ctrl -> color=red brightness=50
```

## 代码逐段讲解

源码：[`main/web_ws2812_main.c`](../03.Sketch/09_WEB_WS2812/main/web_ws2812_main.c)。

### 1. `apply_state` / `color_from_name`

`switch(s_color)` 只点亮对应通道为 `s_brightness`。`color_from_name` 用 `strcasecmp` 识别 red/green/blue/off。

### 2. `INDEX_HTML` 与前端逻辑

内联 CSS 暗色主题；`send(color)` 拼 `/ctrl?brightness=&color=`；`setInterval(...,2000)` 拉 `/status`；`show(d)` 更新按钮高亮与状态条。

### 3. `ctrl_get_handler` 细节

复制 query 到缓冲 → 可选解析 `color`、`brightness`（`strtol` 钳位 0–255）→ 任一变化则 `apply_state()` → 日志 `ctrl -> color=...` → **直接调用** `status_get_handler` 把 JSON 作为响应（浏览器一次请求即得新状态）。

### 4. `start_web_server`

`config.server_port = HTTP_PORT`；`httpd_start` 后 `httpd_register_uri_handler` 注册 `/`、`/ctrl`、`/status`。

### 5. `app_main` 与 Wi-Fi

`wifi_event_handler` 在 `GOT_IP` 打印 `open http://...`。失败连网则 return，不启 HTTP。灯在连网前已 `ws2812_init` 且 `apply_state` 灭灯。

## 常见问题

- 网页打不开：同网段、`http://` 非 `https`；可改端口 8080。
- 灯不变：亮度为 0、GPIO 错误。
- 颜色偏：GRB；Wi-Fi 见 08 章排查。
